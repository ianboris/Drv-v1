# Deriv Digit AI V1

Clean Vite + React + TypeScript mobile-first research console.

## Structure
- index.html
- package.json
- tsconfig.json
- vite.config.ts
- public/manifest.webmanifest
- src/main.tsx
- src/style.css

## Build
npm install
npm run build

## Deploy
Import the repository into Vercel. Framework: Vite. Build command: npm run build. Output directory: dist.
